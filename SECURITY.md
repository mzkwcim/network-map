# Security Policy

## Reporting a Vulnerability
Please do **not** open public issues for security problems.

Email: **wkrak98@gmail.com**

Include:
- affected file/path
- reproduction steps (safe PoC)
- expected impact

## Data safety
This project is designed for public demos:
- IP masking is recommended for screenshots/datasets
- Do not include secrets, tokens, private keys, or real internal addresses in `src/data/*.json`
